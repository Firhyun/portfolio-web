# Portfolio Web (Figma to Code)

A modern, responsive portfolio web application built with React, Vite, and Tailwind CSS, converted from Figma design.

## 🚀 Tech Stack

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **React Router v7**

## 💻 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) and `pnpm` (or `npm`) installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/Firhyun/portfolio-web.git

# Navigate to project directory
cd portfolio-web

# Install dependencies
pnpm install
# or
npm install
```

### Development

```bash
# Start development server
pnpm dev
# or
npm run dev
```

### Build

```bash
# Build for production
pnpm build
# or
npm run build
```
